# Factory-Governance Scope

The DoW AI PM Builder Template governs and evidences the AI-driven production method itself. The factory behavior, not merely the generated product, is subject to the management-system evidence chain.

## Baseline Factory Frameworks

| Framework | Treatment |
|---|---|
| CPMAI | Authoritative lifecycle backbone for phase structure and discovery-first execution |
| ISO/IEC 42001 | Authoritative AIMS management-system target for factory behavior |
| NIST AI RMF | Authoritative risk-function overlay for AI factory trustworthiness evidence |
| ISO/IEC 27001 | Crosswalk candidate when authoritative source clauses are supplied/confirmed |
| ISO/IEC 27701 | Reference Needed — no authoritative clause mapping until full standard is available |

## Conditional Product Overlays

CMMC, FedRAMP, HIPAA, SOC 2, and similar frameworks are product/engagement overlays. They activate only after project classification documents applicability.

## Evidence Required

Generated projects must retain roster, runtime manifest, task assignments, handoffs, phase-gate decisions, verification records, evidence index, standards applicability record, crosswalk status matrix, risk/corrective-action registers, override records, and template provenance.
