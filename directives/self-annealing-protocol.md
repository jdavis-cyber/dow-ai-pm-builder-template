# Self-Annealing Protocol

Every accountable agent must validate upstream inputs, execute only scoped work, verify outputs, and correct root causes before handoff.

Required records:

- `directives/templates/agent-handoff-record.md` for handoffs.
- `directives/templates/self-annealing-record.md` when an error, gap, or failed verification is found.
- `docs/verification/evidence-index.md` updates for objective evidence.

Security & Compliance Officer reviews compliance-impacting self-annealing records before phase gates.
