# AI Governance Framework — Factory Evidence Model

This template applies governance to the AI-driven software factory itself. Every generated project must preserve evidence that the production method was controlled, reviewed, and traceable.

## Baseline Scope

- CPMAI structures the lifecycle and discovery-first phase gates.
- ISO/IEC 42001 frames the AI Management System target for factory behavior.
- NIST AI RMF frames risk identification and trustworthiness evidence.
- ISO/IEC 27001 is a crosswalk candidate when authoritative source clauses are supplied or confirmed.
- ISO/IEC 27701 remains **Reference Needed / Not Authoritatively Mapped** until an authoritative reference is available.

## Conditional Overlays

Product-specific regulatory overlays are conditional. CMMC, FedRAMP, HIPAA, SOC 2, and other sector controls must be activated by documented classification. Do not claim universal applicability without evidence.

## Fail-Closed Rule

If evidence is unavailable, the claim remains a gap. If a gate depends on that evidence, the Security & Compliance Officer blocks advancement unless an authorized override register entry exists.
