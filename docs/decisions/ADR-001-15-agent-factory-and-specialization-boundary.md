# ADR-001: 15-Agent Factory and Specialization Boundary

## Status
Accepted

## Context

The template must instantiate a governed AI software factory with clear accountability and auditable evidence. Prior language blurred accountable agents, runtime packages, and specialization packages.

## Decision

- Use 15 permanent accountable agents as the factory team.
- Always install Security & Compliance Officer.
- Treat the 136 VoltAgent TOMLs as specialization/capability packages mapped to accountable owners.
- Govern the factory behavior itself as an AI Management System demonstration.
- Keep ISO/IEC 27701 gap-labeled as Reference Needed / Not Authoritatively Mapped until an authoritative reference is available.
- Treat product frameworks such as CMMC, FedRAMP, HIPAA, and SOC 2 as conditional overlays.

## Consequences

Validation can prove the same accountable roster exists in SOULs, runtime manifests, docs, and generated projects. Specialization packages add capability without diluting accountability. Some framework mappings remain intentionally incomplete until authoritative references are available.
